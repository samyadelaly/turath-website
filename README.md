# مشروع موقع تراث - الحزمة المسطحة بدون مجلدات فرعية (Flat Structure)

هذه النسخة مصممة خصيصاً لتكون **مسطحة 100% بدون أي مجلدات فرعية (No Subfolders)**.
جميع الملفات موضوعة مباشرة في الجذر الرئيسي لتسهيل رفعها مباشرة إلى GitHub عبر المتصفح دون مشاكل المجلدات الفرعية.

## طريقة الرفع إلى GitHub:
1. قم بفك ضغط هذا الملف.
2. ارفع كافة الملفات الموجودة بداخله مباشرة إلى المستودع الرئيسي في GitHub (بحيث يكون index.html و main.tsx و package.json في الصفحة الرئيسية للمستودع مباشرة).
3. عند ربط المستودع مع Vercel، سيتعرف Vercel على المشروع فوراً ويقوم بتنفيذ الأمر bun run build أو npm run build بنجاح دون أي أخطاء.

## التشغيل محلياً:
```bash
npm install
npm run dev
```
