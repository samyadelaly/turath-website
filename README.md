# TURATH Egypt | تراث للصناعات النحاسية
Handcrafted Brass, Copper & Decorative Metals from Historic Cairo, Egypt.

## هيكل المجلد المسطح بالكامل (Pure Flat - Single Folder Structure)

تم تجهيز وتوليد هذه الحزمة بنمط مسطح نقي بدون أي مجلدات فرعية داخلية (No internal subfolders):
- جميع الملفات البرمجية، المكونات (Components)، الأنماط (Styles)، الصور، وملفات السيرفر موجودة مباشرة في المجلد الرئيسي.
- تم ضبط كافة مسارات الاستيراد (Imports) للعمل بنمط مسطح مباشر متوافق 100% مع Vercel, Netlify, و GitHub.

### التشغيل المحلي (Local Development):
1. افتح موجه الأوامر (Terminal) في مجلد المشروع:
   ```bash
   npm install
   npm run dev
   ```
2. لبناء نسخة الإنتاج (Production Build):
   ```bash
   npm run build
   ```
